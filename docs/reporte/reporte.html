INTRODUCCIÓN

Un sistema manejador de bases de datos (DBMS por sus siglas en inglés) es un programa que se encarga de guardar, consultar y modificar información de forma organizada. El usuario no trabaja directamente con los archivos en disco, sino que le envía instrucciones al manejador y éste se encarga de leer o escribir los datos y de regresar el resultado.

En este proyecto se construye un manejador sencillo en el que la base de datos tiene una sola tabla, guardada en un archivo de texto, y en el que el manejador se divide en dos programas que corren en computadoras distintas: un servidor, que tiene el archivo y ejecuta las instrucciones, y un cliente, que se conecta al servidor a través de la red para enviarle las instrucciones y mostrar las respuestas.

Arquitectura cliente-servidor

La arquitectura cliente-servidor es una forma de organizar una aplicación en dos partes que se comunican por medio de una red:

  1. Servidor: Es el programa que ofrece un servicio. Permanece en ejecución esperando a que lleguen peticiones, las atiende y regresa una respuesta. En este proyecto el servidor es quien tiene el archivo de la tabla y quien ejecuta los comandos.
  2. Cliente: Es el programa que utiliza el servicio. Se conecta al servidor, le envía peticiones y muestra al usuario las respuestas que recibe. En este proyecto el cliente es la terminal en la que el usuario escribe los comandos SQL.

Con esta organización varios clientes pueden usar el mismo servicio al mismo tiempo desde diferentes máquinas, y los datos se mantienen en un solo lugar. Para que el servidor pueda atender a varios clientes a la vez, en este proyecto se crea un proceso hijo por cada cliente que se conecta, de modo que cada conversación se lleva por separado.

Sockets TCP/IP

Un socket es el mecanismo que ofrece el sistema operativo para que dos programas se comuniquen a través de la red. Para el programa, un socket se maneja como un descriptor de archivo: se le escriben bytes con send y se le leen bytes con recv.

Los sockets de este proyecto son de la familia AF_INET, es decir, utilizan direcciones IP versión 4, y son de tipo SOCK_STREAM, es decir, utilizan el protocolo TCP. TCP es un protocolo orientado a conexión: antes de intercambiar datos, cliente y servidor establecen una conexión, y durante ella TCP garantiza que los bytes lleguen completos y en orden. A cambio, TCP no conserva los límites de cada mensaje; lo que se envía con varias llamadas a send puede llegar en una sola llamada a recv o repartido en varias. Por eso la aplicación necesita definir cómo se separa un mensaje del siguiente.

Un detalle importante es el orden de los bytes. Los números de puerto se guardan en la estructura de dirección en orden de red, que es el byte más significativo primero. La función htons convierte un número del orden de la máquina al orden de red, y ntohs hace la conversión inversa.

Sistema manejador de bases de datos

Un manejador de bases de datos organiza la información en tablas. Una tabla está formada por columnas, que son los campos que tiene cada dato, y por registros, que son los renglones con los valores. En este proyecto la tabla es Alumno y tiene las columnas Id, Nombre, Apellido, Semestre y Carrera.

Para simplificar, la tabla se representa con un archivo de texto llamado alumno.txt. La primera línea del archivo es la cabecera con los nombres de las columnas y cada línea siguiente es un registro. Los campos se separan con una coma:

Id,Nombre,Apellido,Semestre,Carrera
1,Juan,Perez,5,Computacion
2,Anita,Lopez,8,Electronica

La columna Id es la llave primaria: identifica a cada registro de forma única, no se repite y no puede modificarse. Además es autoincremental, lo que quiere decir que el manejador la asigna de forma automática al insertar un registro, tomando el Id más grande que existe y sumándole uno.

Lenguaje SQL

SQL es el lenguaje con el que se le dan instrucciones a un manejador de bases de datos. El proyecto implementa los cuatro comandos básicos para consultar y modificar una tabla, más un comando propio para cerrar la conexión:

Las dos primeras funciones se encargan de enviar datos. enviar_todo llama a send en un ciclo hasta que se hayan enviado todos los bytes, porque una sola llamada puede enviar menos de los que se le piden. enviar_respuesta envía el texto de la respuesta y después el carácter de fin, que es la señal para que el cliente deje de leer.

recibir_linea lee el comando que envía el cliente. Se lee un byte a la vez hasta encontrar el salto de línea, para no tomar por error el inicio del siguiente comando. La función regresa el número de bytes leídos, cero si el cliente cerró la conexión y menos uno si hubo un error.

 50  /* Lee del socket caracter por caracter hasta el salto de linea.
 51     Regresa cuantos bytes se leyeron, 0 si el cliente cerro o -1 si hubo error */
 52  static int recibir_linea(int fd, char *buf, size_t tam)
 53  {
 54      size_t n = 0;
 55      int leidos = 0;
 56      char c;
 57      ssize_t r;
 58  
 59      while (n < tam - 1) {
 60          r = recv(fd, &c, 1, 0);
 61          if (r < 0)
 62              return -1;
 63          if (r == 0)
 64              break;
 65          leidos++;
 66          if (c == '\n')
 67              break;
 68          buf[n++] = c;
 69      }
 70      buf[n] = '\0';
 71      return leidos;
 72  }

atender_cliente es la conversación completa con un cliente y se ejecuta dentro del proceso hijo. En cada vuelta del ciclo se recibe un comando, se imprime en la terminal del servidor junto con la IP del cliente, y se revisa si es SALIR. Si lo es, se envía una despedida y termina el ciclo. Si no, el comando se pasa a sql_procesar, que arma la respuesta, y ésta se envía al cliente.

La función principal sigue la secuencia típica de un servidor TCP. Primero se crea el socket con socket y se activa la opción SO_REUSEADDR para poder reiniciar el servidor sin esperar a que el puerto se libere. Después se llena la estructura sockaddr_in con la familia AF_INET, la dirección INADDR_ANY para aceptar conexiones por cualquier interfaz y el puerto convertido a orden de red con htons. Con bind se asocia el socket a esa dirección y con listen se pone a escuchar.

La llamada a signal con SIGCHLD hace que el sistema operativo recoja de manera automática a los procesos hijos cuando terminan, para que no queden procesos zombie.

En el ciclo principal, accept se bloquea hasta que llega un cliente y regresa un nuevo descriptor para hablar con él. Se imprime la fecha, la hora y la IP del cliente, que se obtiene con inet_ntoa. Enseguida se llama a fork: el proceso hijo cierra el socket de escucha, atiende al cliente y termina; el proceso padre cierra el descriptor del cliente y regresa a accept para esperar al siguiente. Así, cada cliente tiene su propio proceso y varios pueden estar conectados al mismo tiempo.

 39  static int recibir_respuesta(int sd)
 40  {

 43      ssize_t i;
 44  
 45      while (1) {
 46          n = recv(sd, buf, sizeof(buf), 0);

En la función principal se crea el socket, se obtiene la dirección del servidor con gethostbyname, que acepta tanto una IP como un nombre, y se copia a la estructura sockaddr_in junto con el puerto en orden de red. Con connect se establece la conexión.

Después viene el ciclo de la conversación. El cliente muestra el indicador SQL>, lee una línea del teclado, le quita los espacios sobrantes y la envía al servidor con un salto de línea al final. Las líneas vacías no se envían y la combinación Ctrl-D se trata como SALIR para no dejar la conexión abierta.

 97      memset((char *) &server, 0, sizeof(struct sockaddr_in));
 98      server.sin_family = AF_INET;
 99      server.sin_port = htons((u_short) puerto);
100      memcpy(&server.sin_addr, sp->h_addr, sp->h_length);
101  
102      /* Conexion con el servidor */
103      if (connect(sd, (struct sockaddr *) &server, sizeof(struct sockaddr_in)) < 0) {
104          perror("connect");
105          exit(1);
106      }
107  
108      printf("Conectado al servidor %s:%d\n", inet_ntoa(server.sin_addr), puerto);
109      printf("Escribe un comando SQL por linea. SALIR para terminar.\n");
110  
111      /* Se lee un comando del teclado, se envia y se espera la respuesta */
112      while (1) {
113          printf("SQL> ");
114          fflush(stdout);
115  
116          if (fgets(linea, sizeof(linea), stdin) == NULL) {
117              printf("\n");
118              strcpy(linea, CMD_SALIR);
119          }
120  
121          recortar_cadena(linea);
122          if (linea[0] == '\0')
123              continue;
124  
125          es_salir = (strcasecmp(linea, CMD_SALIR) == 0);
126  
127          snprintf(peticion, sizeof(peticion), "%s\n", linea);
128          if (enviar_todo(sd, peticion, strlen(peticion)) != 0) {
129              printf("No se pudo enviar el comando. El servidor cerro la conexion.\n");
130              break;
131          }
132  
133          if (recibir_respuesta(sd) != 0) {
134              printf("El servidor cerro la conexion.\n");
135              break;
136          }
137  
138          if (es_salir)
139              break;
140      }
141  
142      close(sd);
143      return 0;
144  }

En tabla.c está la lógica para pasar del archivo a la memoria y de regreso. La idea general es cargar la tabla completa en memoria, trabajar ahí y, si hubo cambios, reescribir el archivo entero. Como el servidor crea un proceso por cliente, dos procesos podrían escribir el archivo al mismo tiempo; para evitarlo, mientras una tabla está cargada su archivo se bloquea con flock: con bloqueo compartido si solo se va a leer y con bloqueo exclusivo si se va a modificar.

tabla_dividir_campos recorre una línea buscando comas y copia cada pedazo como un campo, quitándole los espacios. Se usa para la cabecera, para cada registro y también para la lista de valores del INSERT. nombre_valido revisa que el nombre de la tabla solo tenga letras, dígitos y guion bajo, de modo que no se pueda abrir un archivo fuera de la carpeta de datos.

  4   * se reescribe el archivo. Mientras esta cargada, el archivo queda
  5   * bloqueado para que dos procesos no lo escriban al mismo tiempo.

 18  /* Recorre la linea buscando comas y copia cada pedazo como un campo */
 19  int tabla_dividir_campos(char *linea, char campos[][MAX_VALOR])
 20  {
 21      int n = 0;
 22      char *token = linea;
 23      char *coma;
 24  
 25      while (n < MAX_COLUMNAS) {
 26          coma = strchr(token, SEPARADOR);
 27          if (coma != NULL)
 28              *coma = '\0';
 29          strncpy(campos[n], token, MAX_VALOR - 1);
 30          campos[n][MAX_VALOR - 1] = '\0';
 31          recortar_cadena(campos[n]);
 32          n++;
 33          if (coma == NULL)
 34              break;
 35          token = coma + 1;
 36      }
 37      return n;
 38  }

 40  /* El nombre de la tabla solo puede tener letras, digitos y guion bajo */
 41  static int nombre_valido(const char *nombre)
 42  {
 43      size_t i;
 44  
 45      if (nombre[0] == '\0')
 46          return 0;
 47      for (i = 0; nombre[i] != '\0'; i++) {
 48          if (!isalnum((unsigned char) nombre[i]) && nombre[i] != '_')
 49              return 0;
 50      }
 51      return 1;
 52  }

tabla_cargar forma la ruta del archivo con el nombre de la tabla en minúsculas, por ejemplo Alumno se convierte en datos/alumno.txt. Abre el archivo en modo lectura o en modo lectura y escritura según se pida, lo bloquea, reserva memoria para los registros y lee la primera línea como cabecera. Después lee cada línea siguiente como un registro, ignorando las líneas vacías. Si algo falla, deja un mensaje en el parámetro error y regresa menos uno.

 54  /* Forma la ruta del archivo con el nombre en minusculas, lo abre, lo bloquea
 55     y lee la cabecera y despues cada registro */
 56  int tabla_cargar(const char *nombre, int escritura, Tabla *t, char *error)
 57  {
 58      char linea[MAX_LINEA];
 59      char nombre_min[MAX_VALOR];
 60      size_t i;
 61  
 62      memset(t, 0, sizeof(Tabla));
 63      strncpy(t->nombre, nombre, MAX_VALOR - 1);
 64      t->escritura = escritura;
 65  
 66      if (!nombre_valido(nombre)) {
 67          snprintf(error, TAM_ERROR, "ERROR: nombre de tabla invalido '%s'", nombre);
 68          return -1;
 69      }
 70  
 71      for (i = 0; nombre[i] != '\0' && i < MAX_VALOR - 1; i++)
 72          nombre_min[i] = (char) tolower((unsigned char) nombre[i]);
 73      nombre_min[i] = '\0';
 74      snprintf(t->ruta, sizeof(t->ruta), "%s/%s%s", DIRECTORIO_DATOS, nombre_min, EXTENSION_TABLA);
 75  
 76      t->archivo = fopen(t->ruta, escritura ? "r+" : "r");
 77      if (t->archivo == NULL) {
 78          snprintf(error, TAM_ERROR, "ERROR: la tabla '%s' no existe, no se encontro el archivo %s",
 79                   nombre, t->ruta);
 80          return -1;
 81      }
 82  
 83      if (flock(fileno(t->archivo), escritura ? LOCK_EX : LOCK_SH) != 0) {
 84          snprintf(error, TAM_ERROR, "ERROR: no se pudo bloquear el archivo %s", t->ruta);
 85          tabla_liberar(t);
 86          return -1;
 87      }
 88  
 89      t->registros = calloc(MAX_REGISTROS, sizeof(Registro));
 90      if (t->registros == NULL) {
 91          snprintf(error, TAM_ERROR, "ERROR: sin memoria para cargar la tabla");
 92          tabla_liberar(t);
 93          return -1;
 94      }
 95  
 96      if (fgets(linea, sizeof(linea), t->archivo) == NULL) {
 97          snprintf(error, TAM_ERROR, "ERROR: el archivo %s esta vacio, no tiene cabecera", t->ruta);
 98          tabla_liberar(t);
 99          return -1;
100      }
101      t->num_columnas = tabla_dividir_campos(linea, t->columnas);
102  
103      while (fgets(linea, sizeof(linea), t->archivo) != NULL) {
104          recortar_cadena(linea);
105          if (linea[0] == '\0')
106              continue;
107          if (t->num_registros >= MAX_REGISTROS) {
108              snprintf(error, TAM_ERROR, "ERROR: la tabla excede el maximo de %d registros", MAX_REGISTROS);
109              tabla_liberar(t);
110              return -1;
111          }
112          tabla_dividir_campos(linea, t->registros[t->num_registros].campos);
113          t->num_registros++;
114      }
115  
116      return 0;
117  }

tabla_guardar vacía el archivo con ftruncate y vuelve a escribir la cabecera y todos los registros, separando los campos con coma. tabla_liberar quita el bloqueo, cierra el archivo y libera la memoria. tabla_indice_columna busca una columna por nombre sin distinguir mayúsculas y tabla_siguiente_id busca el Id más grande y le suma uno, que es el valor que recibe el siguiente registro insertado.

119  /* Vacia el archivo y vuelve a escribir la cabecera y todos los registros */
120  int tabla_guardar(Tabla *t, char *error)
121  {
122      int i, j;
123  
124      if (!t->escritura || t->archivo == NULL) {
125          snprintf(error, TAM_ERROR, "ERROR: la tabla no se abrio para escritura");
126          return -1;
127      }
128  
129      rewind(t->archivo);
130      if (ftruncate(fileno(t->archivo), 0) != 0) {
131          snprintf(error, TAM_ERROR, "ERROR: no se pudo escribir el archivo %s", t->ruta);
132          return -1;
133      }
134  
135      for (j = 0; j < t->num_columnas; j++)
136          fprintf(t->archivo, "%s%c", t->columnas[j],
137                  (j < t->num_columnas - 1) ? SEPARADOR : '\n');
138  
139      for (i = 0; i < t->num_registros; i++) {
140          for (j = 0; j < t->num_columnas; j++)
141              fprintf(t->archivo, "%s%c", t->registros[i].campos[j],
142                      (j < t->num_columnas - 1) ? SEPARADOR : '\n');
143      }
144  
145      if (fflush(t->archivo) != 0) {
146          snprintf(error, TAM_ERROR, "ERROR: no se pudo escribir el archivo %s", t->ruta);
147          return -1;
148      }
149      return 0;
150  }

Las siguientes funciones son de apoyo para analizar los comandos. buscar_palabra localiza una palabra clave como VALUES, SET o WHERE sin distinguir mayúsculas y verificando que sea una palabra completa. copiar_entre copia el pedazo de comando que hay entre dos posiciones, por ejemplo lo que está entre SET y WHERE. separar_asignacion parte una expresión de la forma columna=valor en sus dos partes. cumple_condicion compara el campo de un registro con el valor de la condición WHERE.

 31  /* Busca una palabra clave dentro del comando sin distinguir mayusculas.
 32     Solo cuenta si esta separada del resto por espacios o parentesis */
 33  static const char *buscar_palabra(const char *texto, const char *palabra)
 34  {
 35      size_t len = strlen(palabra);
 36      const char *p;
 37  
 38      for (p = texto; *p != '\0'; p++) {
 39          if (strncasecmp(p, palabra, len) != 0)
 40              continue;
 41          if (p != texto && !isspace((unsigned char) p[-1]) && p[-1] != ')')
 42              continue;
 43          if (p[len] != '\0' && !isspace((unsigned char) p[len]) && p[len] != '(')
 44              continue;
 45          return p;
 46      }
 47      return NULL;
 48  }

 50  /* Copia el texto que hay entre dos posiciones y le quita los espacios */
 51  static void copiar_entre(const char *inicio, const char *fin, char *destino, size_t tam)
 52  {
 53      size_t len = (fin > inicio) ? (size_t) (fin - inicio) : 0;
 54  
 55      if (len >= tam)
 56          len = tam - 1;
 57      memcpy(destino, inicio, len);
 58      destino[len] = '\0';
 59      recortar_cadena(destino);
 60  }

 80      return (columna[0] == '\0') ? -1 : 0;

Comando INSERT

sql_insert revisa que el comando empiece con INSERT INTO y el nombre de la tabla, localiza la palabra VALUES y toma el texto que hay entre el paréntesis que abre y el que cierra. Ese texto se separa por comas y a cada valor se le quitan las comillas si las tiene. Después se carga la tabla en modo escritura y se verifica que el número de valores sea igual al número de columnas menos uno, porque el Id no se envía. Se forma el registro nuevo con el Id que regresa tabla_siguiente_id, se agrega al final y se guarda el archivo. La respuesta indica el Id que recibió el registro.

122  /* INSERT INTO tabla VALUES valor1,valor2,...
123     Toma los valores entre parentesis, les asigna el siguiente Id
124     y agrega el registro al final de la tabla */
125  static void sql_insert(const char *cmd, char *resp, size_t tam)
126  {
127      char k1[16], k2[16], tabla[MAX_VALOR];
128      char valores[MAX_LINEA];
129      char campos[MAX_COLUMNAS][MAX_VALOR];
130      char error[TAM_ERROR];
131      const char *values, *abre, *cierra, *p;
132      size_t len;
133      Tabla t;
134      Registro nuevo;
135      int n, j, nuevo_id;
136  
137      if (sscanf(cmd, "%15s %15s %63s", k1, k2, tabla) != 3 || strcasecmp(k2, "INTO") != 0) {
138          agregar(resp, tam, "ERROR de sintaxis. Uso: INSERT INTO <tabla> VALUES (v1,v2,...)\n");
139          return;
140      }
141  
142      values = buscar_palabra(cmd, "VALUES");
143      abre = (values != NULL) ? strchr(values, '(') : NULL;
144      cierra = (values != NULL) ? strrchr(values, ')') : NULL;
145      if (abre == NULL || cierra == NULL || cierra < abre) {
146          agregar(resp, tam, "ERROR de sintaxis. Uso: INSERT INTO <tabla> VALUES (v1,v2,...)\n");
147          return;
148      }
149      for (p = cierra + 1; *p != '\0'; p++) {
150          if (!isspace((unsigned char) *p)) {
151              agregar(resp, tam, "ERROR de sintaxis: texto inesperado despues de ')'\n");
152              return;
153          }
154      }
155  
156      len = (size_t) (cierra - abre - 1);
157      if (len >= sizeof(valores)) {
158          agregar(resp, tam, "ERROR: la lista de valores es demasiado larga\n");
159          return;
160      }
161      memcpy(valores, abre + 1, len);
162      valores[len] = '\0';
163  
164      n = tabla_dividir_campos(valores, campos);
165      for (j = 0; j < n; j++)
166          quitar_comillas(campos[j]);
167  
168      if (tabla_cargar(tabla, 1, &t, error) != 0) {
169          agregar(resp, tam, "%s\n", error);
170          return;
171      }
172  
173      if (n != t.num_columnas - 1) {
174          agregar(resp, tam, "ERROR: se esperaban %d valores (", t.num_columnas - 1);
175          for (j = 1; j < t.num_columnas; j++)
176              agregar(resp, tam, "%s%s", t.columnas[j], (j < t.num_columnas - 1) ? "," : "");
177          agregar(resp, tam, ") y se recibieron %d\n", n);
178          tabla_liberar(&t);
179          return;
180      }
181      for (j = 0; j < n; j++) {
182          if (campos[j][0] == '\0') {
183              agregar(resp, tam, "ERROR: el valor de la columna %s esta vacio\n", t.columnas[j + 1]);
184              tabla_liberar(&t);
185              return;
186          }
187      }
188      if (t.num_registros >= MAX_REGISTROS) {
189          agregar(resp, tam, "ERROR: la tabla esta llena (%d registros)\n", MAX_REGISTROS);
190          tabla_liberar(&t);
191          return;
192      }
193  
194      memset(&nuevo, 0, sizeof(nuevo));
195      nuevo_id = tabla_siguiente_id(&t);
196      snprintf(nuevo.campos[0], MAX_VALOR, "%d", nuevo_id);
197      for (j = 0; j < n; j++)
198          strcpy(nuevo.campos[j + 1], campos[j]);
199  
200      t.registros[t.num_registros] = nuevo;
201      t.num_registros++;
202  
203      if (tabla_guardar(&t, error) != 0) {
204          agregar(resp, tam, "%s\n", error);
205          tabla_liberar(&t);
206          return;
207      }
208  
209      agregar(resp, tam, "OK: registro insertado en %s con Id=%d\n", t.nombre, nuevo_id);

Comando UPDATE

sql_update localiza las palabras SET y WHERE; las dos son obligatorias, para no modificar toda la tabla por accidente. El texto entre SET y WHERE son las asignaciones, que pueden ser varias separadas por coma, y el texto después de WHERE es la condición. Se carga la tabla, se verifica que todas las columnas existan y se rechaza el comando si alguna asignación intenta cambiar la primera columna, que es el Id. Después se recorren los registros y a los que cumplen la condición se les copian los valores nuevos. Si ningún registro cumplió, se responde con un error y el archivo no se toca; si hubo cambios, se guarda y se responde cuántos registros se actualizaron.

213  /* UPDATE tabla SET columna=valor WHERE columna=valor
214     Cambia los valores indicados en los registros que cumplen la condicion.
215     La columna Id no se puede modificar */
216  static void sql_update(const char *cmd, char *resp, size_t tam)
217  {
218      char k1[16], tabla[MAX_VALOR];
219      char asignaciones[MAX_LINEA], condicion[MAX_LINEA];
220      char col_where[MAX_VALOR], val_where[MAX_VALOR];
221      char cols[MAX_COLUMNAS][MAX_VALOR], vals[MAX_COLUMNAS][MAX_VALOR];
222      int idx[MAX_COLUMNAS];
223      char error[TAM_ERROR];
224      const char *set, *where;
225      char *token, *coma;
226      Tabla t;
227      int num_asig = 0, idx_where, afectados = 0, i, j;
228  
229      if (sscanf(cmd, "%15s %63s", k1, tabla) != 2) {
230          agregar(resp, tam, "ERROR de sintaxis. Uso: UPDATE <tabla> SET <columna>=<valor> WHERE <columna>=<valor>\n");
231          return;
232      }
233  
234      set = buscar_palabra(cmd, "SET");
235      where = buscar_palabra(cmd, "WHERE");
236      if (set == NULL || where == NULL || where < set) {
237          agregar(resp, tam, "ERROR de sintaxis. Uso: UPDATE <tabla> SET <columna>=<valor> WHERE <columna>=<valor>\n");
238          return;
239      }
240  
241      copiar_entre(set + strlen("SET"), where, asignaciones, sizeof(asignaciones));
242      copiar_entre(where + strlen("WHERE"), cmd + strlen(cmd), condicion, sizeof(condicion));
243  
244      if (separar_asignacion(condicion, col_where, val_where) != 0) {
245          agregar(resp, tam, "ERROR de sintaxis en WHERE. Uso: WHERE <columna>=<valor>\n");
246          return;
247      }
248  
249      token = asignaciones;
250      while (token != NULL) {
251          if (num_asig >= MAX_COLUMNAS) {
252              agregar(resp, tam, "ERROR: demasiadas asignaciones en SET\n");
253              return;
254          }
255          coma = strchr(token, ',');
256          if (coma != NULL)
257              *coma = '\0';
258          if (separar_asignacion(token, cols[num_asig], vals[num_asig]) != 0) {
259              agregar(resp, tam, "ERROR de sintaxis en SET. Uso: SET <columna>=<valor>[, <columna>=<valor>]\n");
260              return;
261          }
262          num_asig++;
263          token = (coma != NULL) ? coma + 1 : NULL;
264      }
265  
266      if (tabla_cargar(tabla, 1, &t, error) != 0) {
267          agregar(resp, tam, "%s\n", error);
268          return;
269      }
270  
271      idx_where = tabla_indice_columna(&t, col_where);
272      if (idx_where < 0) {
273          agregar(resp, tam, "ERROR: la columna '%s' no existe en %s\n", col_where, t.nombre);
274          tabla_liberar(&t);
275          return;
276      }
277      for (j = 0; j < num_asig; j++) {
278          idx[j] = tabla_indice_columna(&t, cols[j]);
279          if (idx[j] < 0) {
280              agregar(resp, tam, "ERROR: la columna '%s' no existe en %s\n", cols[j], t.nombre);
281              tabla_liberar(&t);
282              return;
283          }
284          if (idx[j] == 0) {
285              agregar(resp, tam, "ERROR: la columna %s es la llave primaria y no puede actualizarse\n",
286                      t.columnas[0]);
287              tabla_liberar(&t);
288              return;
289          }
290          if (vals[j][0] == '\0') {
291              agregar(resp, tam, "ERROR: el valor para la columna %s esta vacio\n", t.columnas[idx[j]]);
292              tabla_liberar(&t);
293              return;
294          }
295      }
296  
297      for (i = 0; i < t.num_registros; i++) {
298          if (!cumple_condicion(&t, i, idx_where, val_where))
299              continue;
300          for (j = 0; j < num_asig; j++)
301              strcpy(t.registros[i].campos[idx[j]], vals[j]);
302          afectados++;
303      }
304  
305      if (afectados == 0) {
306          agregar(resp, tam, "ERROR: ningun registro de %s cumple la condicion %s=%s\n",
307                  t.nombre, col_where, val_where);
308          tabla_liberar(&t);
309          return;
310      }
311  
312      if (tabla_guardar(&t, error) != 0) {
313          agregar(resp, tam, "%s\n", error);
314          tabla_liberar(&t);
315          return;
316      }
317  
318      agregar(resp, tam, "OK: %d registro(s) actualizado(s) en %s\n", afectados, t.nombre);
319      tabla_liberar(&t);
320  }

Comando DELETE

sql_delete funciona de forma parecida. Localiza WHERE, obtiene la condición y carga la tabla. Para eliminar registros se recorre el arreglo con dos índices: los registros que no cumplen la condición se van copiando hacia adelante y los que sí cumplen se dejan fuera. Al final el número de registros se reduce y se guarda el archivo. Los Id de los registros restantes no se vuelven a numerar, porque el Id es la llave primaria y debe mantenerse estable.

322  /* DELETE FROM tabla WHERE columna=valor
323     Quita de la tabla los registros que cumplen la condicion */
324  static void sql_delete(const char *cmd, char *resp, size_t tam)
325  {
326      char k1[16], k2[16], tabla[MAX_VALOR];
327      char condicion[MAX_LINEA];
328      char col_where[MAX_VALOR], val_where[MAX_VALOR];
329      char error[TAM_ERROR];
330      const char *where;
331      Tabla t;
332      int idx_where, eliminados = 0, i, destino;
333  
334      if (sscanf(cmd, "%15s %15s %63s", k1, k2, tabla) != 3 || strcasecmp(k2, "FROM") != 0) {
335          agregar(resp, tam, "ERROR de sintaxis. Uso: DELETE FROM <tabla> WHERE <columna>=<valor>\n");
336          return;
337      }
338  
339      where = buscar_palabra(cmd, "WHERE");
340      if (where == NULL) {
341          agregar(resp, tam, "ERROR de sintaxis. Uso: DELETE FROM <tabla> WHERE <columna>=<valor>\n");
342          return;
343      }
344      copiar_entre(where + strlen("WHERE"), cmd + strlen(cmd), condicion, sizeof(condicion));
345      if (separar_asignacion(condicion, col_where, val_where) != 0) {
346          agregar(resp, tam, "ERROR de sintaxis en WHERE. Uso: WHERE <columna>=<valor>\n");
347          return;
348      }
349  
350      if (tabla_cargar(tabla, 1, &t, error) != 0) {
351          agregar(resp, tam, "%s\n", error);
352          return;
353      }
354  
355      idx_where = tabla_indice_columna(&t, col_where);
356      if (idx_where < 0) {
357          agregar(resp, tam, "ERROR: la columna '%s' no existe en %s\n", col_where, t.nombre);
358          tabla_liberar(&t);
359          return;
360      }
361  
362      /* Los registros que no cumplen se van recorriendo hacia adelante
363         y los que cumplen se dejan fuera */
364      destino = 0;
365      for (i = 0; i < t.num_registros; i++) {
366          if (cumple_condicion(&t, i, idx_where, val_where)) {
367              eliminados++;
368              continue;
369          }
370          if (destino != i)
371              t.registros[destino] = t.registros[i];
372          destino++;
373      }
374      t.num_registros = destino;
375  
376      if (eliminados == 0) {
377          agregar(resp, tam, "ERROR: ningun registro de %s cumple la condicion %s=%s\n",
378                  t.nombre, col_where, val_where);
379          tabla_liberar(&t);
380          return;
381      }
382  
383      if (tabla_guardar(&t, error) != 0) {
384          agregar(resp, tam, "%s\n", error);
385          tabla_liberar(&t);
386          return;
387      }
388  
389      agregar(resp, tam, "OK: %d registro(s) eliminado(s) de %s\n", eliminados, t.nombre);
390      tabla_liberar(&t);
391  }

CONCLUSIONES

Arreola Santander Ricardo

Para resolver el proyecto se construyeron dos programas en C que se comunican por sockets TCP: un servidor que guarda la tabla en un archivo de texto y ejecuta los comandos, y un cliente que se conecta desde otra máquina para enviarlos. Al hacerlo se vio en la práctica la secuencia de llamadas de un servidor, que crea el socket, lo asocia a un puerto, escucha y acepta conexiones, y la del cliente, que resuelve la dirección y se conecta.

Un punto que resultó importante fue que TCP entrega un flujo de bytes y no mensajes separados, por lo que fue necesario acordar un formato: un comando por línea del lado del cliente y un carácter de fin de respuesta del lado del servidor. También se comprobó la utilidad de crear un proceso por cada cliente con fork, lo que permite atender varias conexiones a la vez, y la necesidad de bloquear el archivo para que dos procesos no lo escriban al mismo tiempo.

Con las pruebas entre dos máquinas virtuales se verificó que los cuatro comandos SQL funcionan sobre el archivo, que la columna Id se asigna de forma automática y no puede modificarse, y que el comando SALIR cierra la conexión de forma ordenada. El proyecto permitió unir en una sola aplicación los temas de procesos, sockets y manejo de archivos en Linux.
